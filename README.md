# -Virtual-Laboratory
Laboratorium Maya adalah media pembelajaran digital interaktif berbasis web yang menyajikan materi konsep, teori, arsitektur, klasifikasi, hingga integrasi blended learning. Dilengkapi fitur interaktif, pencarian, dan opsi dua bahasa (ID/EN). Dibuat dengan HTML5, CSS3, dan JS single-file agar ringan, responsif, dan mudah diakses via browser.

https://nuelxv.github.io/-Virtual-Laboratory/
